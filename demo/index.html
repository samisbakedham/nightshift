open experiment · continual learning

nightshift

A language model meets a Python library that did not exist when it was trained. Every day a new module ships. By day it practices, fails, writes itself lessons and invents its own exercises. By night it distills what it learned into its weights. Every answer is graded by running the code. No LLM judges.

The 10-day experiment

base
The untrained model, no docs. The floor.
rag
Docs + lessons pasted into every prompt. Learns instantly, pays in tokens forever.
sft
Nightly fine-tuning on the teacher's verified solutions, plus replay: the base model's correct answers to 8 reasoning prompts. Closed-book at test time.
sdft
Nightly on-policy self-distillation from a frozen teacher that sees the docs, plus replay: the same 8 reasoning prompts, matched to the base model. Closed-book at test time.
